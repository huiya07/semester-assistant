## 平台实际流程（2026-10-25 参赛中心截图，以平台为准）

- 报名后直接进入**省赛**阶段；页面「省赛·待考试」是平台通用模板文案，**本赛道是作品题，没有考试**
- **第一道期限：2026-10-31 15:00 前提交「预指导作品」**，链接 `https://f.kdocs.cn/g/GZcCLbBV/`（WPS 表单）
  - 预指导作品**仅用于预指导**，不作为省赛最终作品；完整作品仍需重新提交至省赛链接
  - 每人**只提交一次**，交前确认好
  - **这是一次免费的提前评审机会，应尽早交一个能跑的版本换取反馈**

### 预指导表单字段（2026-10-25 实拍，7 项，全部必填）

1. **UID** —— 传智杯平台用户 ID
2. **姓名**
3. **您的学校**
4. **提交作品联系人手机号**
5. **完整作品文件链接**（作品文档、作品源码等）—— 上传到百度网盘 / 夸克 / 阿里云盘等，填可访问链接，建议长期有效 + 含提取码
6. **作品介绍文档**（上传文件，≤100MB），必须包含七项：
   1. 项目详情及使用方式
   2. 项目亮点
   3. AI 技术落地使用情况概述
   4. 项目涉及的关键技术
   5. 项目相关图片/照片
   6. 项目之前是否发表过或获奖（没有就写没有）
   7. 若在其他项目基础上优化，说明优化部分
7. **演示视频地址** —— **切勿用百度网盘**，视频须上传 B 站 / 抖音等公开平台，只填视频链接

- **最终省赛作品提交链接暂未公布**，截止仍按 11-18 掌握
- 官方赛道文档里写「作品指导提交截止日期为 2026-11-18」，与平台的 10-31 预指导不一致——**以平台为准**，11-18 视为最终作品截止


## 四件交付物

1. **代码仓库与演进记录**
   - GitHub / Gitee，Public 或给评审访问权限
   - Git 提交历史必须细粒度，**明确禁止一次性提交（initial commit 一把梭）**。每次提交对应一次与 AI 的核心对话或一个功能模块
   - AI 对话历史导出（不支持导出就截图/录屏）：**至少 3 个核心功能迭代**的完整 Prompt 链 —— 我的提问、AI 的修改建议、我如何引导修 Bug
2. **README.md**：十分钟极速复现 —— 环境配置说明、依赖清单、环境变量模板
3. **演示视频**：5–8 分钟，MP4，1080p；**必须含 ≥2 分钟 AI 协同过程复现**（录屏展示 Prompt 生成模块 / 引导修顽固 Bug）
4. **技术文档**：PDF，≤30 页；重点写 意图控制策略、架构设计、可复现性论证

## 评分权重

| 维度 | 权重 |
|---|---|
| 过程可复现性与演进链路 | 25% |
| 解题有效性与实用价值 | 25% |
| 方法创新性与意图控制 | 20% |
| 工程质量与架构设计 | 15% |
| 用户体验与产品精细度 | 15% |

省赛奖项比例：一等 10% / 二等 20% / 三等 30% / 优秀 30%（最高为上限，另有最低分数线）。一二三等奖晋级决赛。

## 硬性禁止项

- 一次性提交、事后补凑的 Prompt 记录
- 直接使用已有开源项目包装参赛
- 公开仓库出现 API key 等敏感信息（必须环境变量）
- 抄袭、信息作假

## 技术栈

不强制。推荐 React/Next.js、Vue/Nuxt、Python/FastAPI、Node.js、Go、Flutter。AI 工具推荐 Cursor / Windsurf / Trae / 通义灵码；命题背景段落点名 Claude Code，使用合规。
