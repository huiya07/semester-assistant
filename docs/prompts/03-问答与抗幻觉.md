# 功能：问答与抗幻觉（2026-10-25）

## 目标
检索 → 让模型基于片段作答 → 每条结论带 `[n]` 引用 → 没依据就说找不到。

## 关键提问（原文摘录）
1. 「无依据时模型输出 NO_ANSWER → 后端降级为 not_found；空库直接不调模型。」
2. 「模型可能编造 [7]，而检索结果只有 5 条 —— 引用编号必须逐个校验。」

## 三层防线（按拦截顺序）
1. **检索层**：最佳 distance > 0.65 直接返回 not_found，**不调模型**（省钱 + 从源头阻止编造）。
   实测麻婆豆腐 = 0.6515，正好被拦在外面。
2. **提示层**：system prompt 硬约束「只能用给定片段、每条结论标 [n]、没有依据只输出 NO_ANSWER、不得编造页码/数字」。
3. **后处理层**：正则提取答案里的 `[n]`，逐个检查是否在 1..len(hits) 范围内。
   - 引用的编号**全部越界** → 判定为编造，整体降级 not_found
   - 部分越界 → 只保留有效的
   - 一个引用都没有 → 模型没守规则，同样降级

## 踩到的问题：正确答案被挤出了前 5

第一次实测「How many attention heads does the base model use?」返回 not_found，
但最佳距离只有 0.37（很相关）。

排查顺序：
1. 先怀疑 prompt → 不是，模型是**正确地**说找不到
2. 再看检索结果 → 正确答案（p5，`h = 8 parallel attention layers`）**排在第 6 位**，被「P100 GPU 训练」「label smoothing」这类片段挤掉
3. 前 5 名距离 0.373~0.387，第 6 名 0.401，**差距只有 0.03**

处理：`top_k` 默认 5 → 8。重测立刻答对：`h = 8 个并行注意力层 [6]`，引用指向 p5。

教训：**not_found 有两种原因**——「资料里真没有」和「检索没召回」。不能看到 not_found 就以为抗幻觉生效了，
必须回头看检索结果里到底有没有答案。这次模型没错，是召回不够。

## 五个验收用例
| 用例 | 结果 |
|---|---|
| 英文文档 + 英文提问 | ok，`h=8 [6]` → p5 ✅ |
| 中文文档 + 中文提问 | ok，`共 5 题 [1]` → p1 ✅ |
| 库外问题（麻婆豆腐） | not_found，距离 0.6515 被阈值拦下，未调模型 ✅ |
| 空库 | not_found，提示「知识库还是空的」✅ |
| 相关但资料里没有（问奖项） | not_found，距离 0.573 调了模型，模型自己输出 NO_ANSWER ✅ |
