## 第 2 点：为什么不跨页

三个理由，从硬到软：

**① 双栏 PDF 的拼接技术上是错的。**

PyMuPDF 按栏提取文本，第 N 页的阅读顺序是「左栏 → 右栏」，第 N+1 页又是「左栏 → 右栏」。你把第 N 页末尾和第 N+1 页开头拼起来，实际接上的是：第 N 页右栏底部 + 页脚 + 页码 + 第 N+1 页左栏顶部。中间夹着噪声，语义是断的。

**② 引用精度。** 赛题要「带原文出处」。跨页的片段只能报「第 3–4 页」，不跨页永远能精确到「第 3 页」——用户能直接翻到那一页验证。
